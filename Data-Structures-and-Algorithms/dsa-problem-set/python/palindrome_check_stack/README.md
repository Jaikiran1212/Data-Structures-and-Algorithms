# Palindrome Check (Single Stack) — Python

## What it does
Checks whether a string is a palindrome by pushing every character
onto a stack, then popping them back off (which comes out in reverse
order) while comparing against the original string read
left-to-right. If every character matches its mirrored counterpart,
the string is a palindrome.

## How to run
```
python3 palindrome_check_stack.py
```

The script runs a small built-in demo (no stdin input needed):
```
True
False
```
(`"malayalam"` is a palindrome, `"hello"` is not.)
