# Data Structures and Algorithms

A collection of Java implementations of common data structures and algorithms, organized by topic. This repo is a work in progress — new folders and implementations will be added over time.

## 📁 Structure

| Folder | Description |
|---|---|
| [`Singly Linked List Implementations/`](./Singly%20Linked%20List%20Implementations) | Singly linked list operations (insertion, traversal, etc.) |
| [`Sorting techniques/`](./Sorting%20techniques) | Sorting algorithms implemented on both arrays/plain data and linked list nodes |

> More folders will be added here as the repo grows (e.g. Trees, Graphs, Stacks, Queues, Searching).

## 🛠 Requirements

- Java (JDK 8+)

## ▶️ Running a file

```bash
javac <filename>.java
java <ClassName>
```

## 📌 Notes

- Each subfolder has its own `README.md` explaining what's inside it in more detail.
- This repo is meant as a personal learning/reference log — implementations prioritize clarity over micro-optimization.
