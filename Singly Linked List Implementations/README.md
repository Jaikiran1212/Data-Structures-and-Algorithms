# Singly Linked List Implementations

Java implementations covering the basics of singly linked lists.

## 📄 Files

| File | Description |
|---|---|
| `SLList.java` | Core singly linked list implementation with node-based structure and insertion at the end |

> New singly linked list operations (delete, reverse, search, etc.) will be added to this folder over time — this table will be updated as files are added.

## 🧠 Concepts covered

- Node structure (`data` + `next` pointer)
- Insertion at the end of the list

## ▶️ Running

```bash
javac SLList.java
java SLList
```
