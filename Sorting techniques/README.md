# Sorting Techniques

Java implementations of classic sorting algorithms, each done two ways:
- **`_data`** — operating on a linked list where nodes are manipulated by swapping data values
- **`_node`** — operating on a linked list where sorting is done by rearranging the nodes/pointers themselves

## 📄 Files

| File | Algorithm | Style |
|---|---|---|
| `Bubble_Sort_data.java` | Bubble Sort | Data-swap based |
| `Bubble_Sort_node.java` | Bubble Sort | Node-rearrangement based |
| `Insertion_Sort_data.java` | Insertion Sort | Data-swap based |
| `Insertion_Sort_node.java` | Insertion Sort | Node-rearrangement based |
| `Selection_Sort_data.java` | Selection Sort | Data-swap based |
| `Selection_Sort_node.java` | Selection Sort | Node-rearrangement based |


## ▶️ Running

```bash
javac <filename>.java
java <ClassName>
```
